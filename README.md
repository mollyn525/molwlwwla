# 八段锦 iOS 采集 0.2.4

使用 SwiftUI、CoreBluetooth 和 Foundation 的原生 iOS 采集项目，最低 iOS 17，无第三方运行库。此公开仓库仅包含源码、构建脚本和合成测试夹具；不包含真实采集记录、设备名册、账号、证书或签名。

## 功能

- 15部位设备管理、实时惯性数据、佩戴核验及参考姿态。
- 八个动作各15个固定编号，补录追加尝试、保留旧记录。
- 正式采集使用15台就绪设备；加速度和角速度平均接收率各严格大于40Hz，统计分母包含数据间隙。
- 磁场和四元数继续记录；分类ZIP导出包含原始通知、解析数据、事件、摘要及兼容TXT。
- 统一配置、加速度校准、操作审计和历史结果查看。
- 不添加录后回放，声音和振动保持关闭。

## 0.2.3 并行加速度校准

最多15台一起进行校准：每台独立读取旧值、检查姿态、启动、计时、恢复等待、复核、保存和显示结果。单台断线、回读超时、姿态不满足或复核失败只结束该台，其他设备继续。指令使用已有公平调度依次提交，不承诺硬件同步启动。统一配置功能仍逐台执行。

结果页同时显示本批每台的进行中/结束状态与保存提交状态，并保留历次结果。所有命令和原始通知按设备及操作编号分别归属；共用一个批次审计文件句柄减少逐通知打开文件的开销。离开前台、蓝牙整体不可用、用户取消或共同审计故障会停止整个批次。每台设独立60秒操作上限，不跨断线自动恢复校准。

## 保留的校准恢复机制

短暂停顿后等待数据恢复并重新取得约3秒完整稳定窗口。保存前和保存后各最多额外等待8秒，不重复发送启动或保存指令。明显运动、全程500ms间隙、断线、取消及超时仍终止后续操作。

“设置 → 硬件加速度校准 → 查看加速度校准结果”显示每次操作的保存提交状态、复核结果、原因及可用的三轴前后均值与变化量；兼容历史日志，缺失字段不补造。输出读数变化不是内部补偿系数，静态复核不是绝对精度认证。发送成功不等于收到设备内部完成应答。

真实校准前必须按传感器坐标确认全组原始+Z朝上并放稳。并行全组通常约20–40秒，请预留1分钟并保持到批次结束。实际耗时及真实15台并行效果需要硬件验证。更新使用相同签名身份及应用标识，不卸载旧App。

## 构建

在项目目录运行：

```sh
python3 tools/generate_project.py
python3 tools/validate_source.py
python3 tools/package_source.py
```

结构检查不等于编译。在配有Xcode的Mac上运行：

```sh
bash tools/build_macos.sh
```

构建流程运行核心XCTest、独立ZIP/TXT核验、模拟器界面测试及iPhone ARM64编译，生成需要本地签名的无签名IPA。公开云构建不使用Apple账号或签名凭据。运行状态以对应提交的构建结果为准；软件测试不能替代真实设备验收。
